# Passive Voice во всех временах

Учебный интерактивный лендинг по английской грамматике: страдательный залог во всех восьми временах.
Одна самодостаточная HTML-страница, без сборки и зависимостей.

## Что внутри

- **Объяснение в разговорном стиле** — короткие истории вместо таблицы на 24 клетки
- **Формула-бутерброд** `to be + V3` с живым конструктором: 8 времён × 4 глагола × `by`
- **Две многоступенчатые диаграммы** — алгоритм из 5 шагов и маршрут от простого к сложному
  (mobile-first: вертикальная лестница на телефоне, зигзаг на десктопе)
- **Тренажёр на 16 заданий** трёх типов: выбор формы, сборка предложения из слов, ввод руками.
  Разбор каждого ответа, кнопка «показать ответ», работа над ошибками
- **Озвучка** через Web Speech API — автоопределение русского и английского в смешанном тексте,
  регулятор скорости
- **6 видеоуроков** с YouTube и заданиями к каждому
- **Трекер прогресса** на 9 модулей с сохранением в localStorage
- Анимации отрисовки SVG, stagger-reveal, параллакс; поддержка `prefers-reduced-motion`

## Запуск

Открыть `index.html` в браузере. Больше ничего не нужно.

Для локального сервера:

```bash
npx serve .
```

## Зависимости

Ничего не устанавливается. Из сети подгружаются только шрифты Google Fonts
(Montserrat, Inter) и обложки видео с `i.ytimg.com` — без интернета страница
работает, но с системным шрифтом и без превью роликов.

## Совместимость

Chrome, Edge, Safari, Firefox. Озвучка использует системные голоса ОС:
если русского голоса в системе нет, русский текст будет прочитан английским голосом.
